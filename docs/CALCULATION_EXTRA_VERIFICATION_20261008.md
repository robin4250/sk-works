# 同日2現場・同名手当の追加回帰検証

現行の給与関数と実トリガーを隔離PGliteで実行する。架空社員・架空勤務だけを使用し、本番Supabaseへ接続しない。給与方針の新設ではなく、現行の勤務日単位の同名手当集計を検証する。

| 操作 | 期待・実測値 |
|---|---|
| 同日2現場に昼0.5人工・夜0.5人工、各行で同じ道具手当を重複指定 | 基本給5,000+7,500円、道具手当は1日1回500円、総額13,000円 |
| 現場の登録順序を逆転 | 総額13,000円で一致 |
| 同じ値で勤務実績を更新 | 確認者・版番号・内訳・履歴を維持 |
| 昼の現場だけ削除 | 夜7,500+手当500円=8,000円、人工0.5、変更された明細の確認を解除 |
| 最後の勤務実績を削除 | 空の日給自動下書きを除去（架空DB内のみ） |

保存内訳の「基本給」と「道具手当」の合計も保存済みgrossと一致することを検証する。

再実行:

```bash
node tool/verify_payroll_split_site_allowances.mjs /absolute/path/to/node_modules/@electric-sql/pglite/dist/index.js
```

PGliteは既存CIと同じ0.3.14を使用する。日給・時給の有給支給額や通常勤務の夜間時間割増の未登録方針、実機の出勤表・給与明細表示確認を、この成功で完了扱いにしない。
