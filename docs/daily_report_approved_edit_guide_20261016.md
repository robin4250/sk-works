# 承認済み日報の編集・再サインの手順（追補案）

更新日：2026年10月16日

この手順は [#1090](https://github.com/robin4250/sk-works/pull/1090) と [#1093](https://github.com/robin4250/sk-works/pull/1093) を導入した版向けの追補案です。両修正の統合・インストール・実機確認前は、現行版で使える機能として案内しません。

## 修正を申請する人

1. 保存済み一覧から、修正する日報を開きます。同じ日に複数の日報がある場合は、現場・日付・内容を確認します。
2. 「編集・修正を申請」を押し、必要に応じて理由を入力して承認依頼を送ります。
3. 会社で設定された承認担当者の承認を待ちます。申請を送っただけでは日報の編集は始まりません。
4. 承認通知から該当日報を開くか、保存済み一覧から同じ日報を開きます。
5. 「承認済みの編集を開始」を押します。以前のサインを解除し、報告者・責任者の再サインが必要になるという確認を読み、「編集を開始」を押します。キャンセルした場合は編集を開始しません。
6. 作業内容・時間・手当など、必要な内容を修正します。
7. 「報告者サイン」から新しいサインを登録します。修正した内容を確認してからサインします。
8. 「責任者サイン」から新しいサインを入力し、「このサインを確認」を押します。この段階ではまだ編集完了ではありません。
9. 「編集を完了」を押します。保存と確定を確認できた場合に、完了画面が表示されます。
10. 「日報の編集を完了しました。保存して確定しました。」を確認し、「ホームへ戻る」を押します。

修正する内容は、報告者・責任者のサインより先に整えます。内容を変更した場合や報告者サインを登録し直した場合は、保留中の責任者サインを再入力します。

## 承認を担当する人

- 会社で承認担当者に登録され、該当申請を扱う権限がある場合に申請を確認します。
- 申請理由と対象の日報を確認し、承認または却下します。
- 修正申請の承認と、編集後の再サイン・編集完了は別の操作です。承認担当者が承認しただけで日報の修正が完了するわけではありません。
- 一般ユーザー・サブ管理者・閲覧者・管理者という表示名だけで、他人の日報を編集できるようにはなりません。

## 保存失敗・画面の開き直し

| 状況 | 操作 |
|---|---|
| 編集開始を確認できない | 申請と対象日報を再読み込みします。承認済みかどうかを推測して操作しません。 |
| 責任者サイン確認後、編集完了の保存に失敗した | 同じ画面に残り、入力したサインを保持したまま「編集を完了」で再試行します。完了画面が出るまでは完了扱いにしません。 |
| 応答だけ受け取れなかった | 再試行時に保存済み状態を確認します。同じ確定を重ねて行いません。 |
| 編集途中でアプリ・画面を開き直した | 同じ利用者・会社・日報・承認申請を確認できた場合に編集を再開します。責任者の未確定サインは再入力してください。 |
| 日報・サインが他の端末で変更された | 再読み込みし、現在の内容を確認します。古い内容のまま完了したと判断しません。 |
| 利用者や会社が変わった | 元の日報の操作を続けません。対象利用者と会社を確認してください。 |

この追補の「編集を完了」は、承認済みの修正を開始した日報に限る手順です。新規日報と現場訪問の日報は、従来の案内・確定手順を使います。

## ヘルプ監査・採用時の確認

監査対象：main `565a1a2c1fb704fdce91c58efd4d57fc0bce8f91` の `lib/features/help/manual_content.dart`。

- 「日報・責任者サイン」は責任者サインによる確定と、確定後に修正申請が必要なことを説明していますが、報告者サインと承認後の編集開始・再サイン・編集完了の説明がありません。
- 「日報の現場別・月別閲覧」は保存済み一覧と編集への入口を説明していますが、修正完了の手順までは説明していません。
- 「日報修正の承認」は承認担当者による承認を説明していますが、承認と編集完了の違いの説明がありません。
- パンフレットの「日報」も入力・サイン・確定までのため、両修正を正式採用する際に対応する説明を照合します。
- 既存の説明書・パンフレット更新Draft [#1000](https://github.com/robin4250/sk-works/pull/1000) は別の更新内容を保持しています。この追補で既存ファイルや未保存の変更を置き換えません。

採用前に、申請者と承認担当者の実機で、申請→承認→編集開始→報告者サイン保存→責任者サイン確認→編集完了→ホームを確認します。保存失敗後の再試行と、画面を開き直したときの責任者サイン再入力も確認します。
