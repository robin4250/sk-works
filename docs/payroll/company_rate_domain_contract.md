# 会社料率の純粋ドメイン契約

Issue #273の実装基礎。DB、画面、公式取得、給与計算には未接続。
新規Dartモデルは未指定初期値・法的料率を内蔵しない。
率は百分率の百万分の一単位の整数。全体・従業員・会社の負担率を明示的に保存し、単純な半分計算をしない。
所得税は率項目enumに含めず、年度と期間を持つ別の税額表参照型とする。

取得候補と現在設定を分離。適用は選択項目、候補ID、現在version、確認済みフラグ、検証済みフラグ、操作者と日時を必須とする。
適用後の新状態には旧新設定を持つ履歴が同時に含まれ、元状態と未選択項目は保持される。
保険料対象月・給与控除月・納付月をそれぞれ保持する。

確認済みフラグは本人確認ポップアップを代替しない。将来画面で「表示された料率・適用年月・情報元をご自身で確認したうえで適用してください」と表示し、選択候補に対する明示確認から作成する。
資料検証フラグも公式性を自力で検証しない。取得・照合サービスが保険者、都道府県、事業区分等と正式資料を確認する必要がある。
保存adapterは会社IDと管理者権限を確認し、version条件更新と履歴書込を同一transactionで保存する必要がある。
この純粋モデルは権限を付与せず、履歴の永続保存や自動切替を実装しない。
所得税PDFは登録と計算ルール検証を区別する。共通資料公開承認・新年度選択・自動切替は今後の実装対象。

unit testsは不等な明示負担率、候補取得の非更新、選択項目のみ適用、履歴、未確認・未検証・競合・不一致・操作者欠落の拒否を確認する。
この作業環境にFlutter/Dart SDKがないため、実行結果はCIで確認する。
