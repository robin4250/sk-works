# 公式料率取得と標準報酬月額の上下限

既存の「最新の公式料率を取得」を使用する。入力方法・対象期間・対象月選択・明示適用は変更しない。取得は候補登録だけで、会社設定や給与明細を自動更新しない。

協会けんぽ公式 https://www.kyoukaikenpo.or.jp/lp/2026hokenryou/ の報酬選択肢から50等級の標準報酬と収入範囲を読み取る。年度、50行、すべての値と連続する境界を既存計算表と比較し、変更・欠落・重複・不明な書式は拒否する。固定の既存値を取得値として返す処理ではない。

厚生年金の中間32等級は同資料の88,000〜650,000円の範囲を使用し、年金機構公式 https://www.nenkin.go.jp/service/yougo/hagyo/hyojunhoshugetsu.html の現行32等級・最低88,000円・最高650,000円の説明とも照合する。最低等級の下限は0、最高等級は上限なしとする。年金表の開始2020-09より前の保険月への混入を拒否する。

全等級のCSV、実取得資料のSHA256、公式URL、表の適用開始、検証版を既存source.applicabilityに保存する。各文字列512字・20条件以内の既存DB契約を守り、新テーブルやDB構造変更は不要。年金は照合した第二資料のURL・SHA256も保持する。候補・適用設定・変更履歴に同じ根拠を保持する。

画面の「適用月・資料の詳細」は従来どおり折りたたみ、上下限と計算先の基準額、出典を表示する。CSVや内部版名は表示しない。受信側も全50/32行と既存計算表を比較し、根拠なしの過去設定を新規取得済みと表示しない。

2026年一般被保険者の対応表である。未知の改定・年度への自動流用はせず、新版の検証が必要。地域料率や会社の適用月、加入資格、平均月収の入力元をこの表から決めない。任意継続の上限とは区別する。

検証：Node parser/認証handler 25項目、全等級と変換境界のDart照合、既存ボタンと未適用のWidget、既存SQLそのものによる候補登録・明示適用・履歴保持をCIで実行する。署名・本人ID・会社・確定給与・既IPAは変更しない。

実装、main統合、本番Edge配備、利用者による取得・適用、iPhone確認は別状態として記録する。
