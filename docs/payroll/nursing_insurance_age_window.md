# 介護保険の年齢・保険月境界

Issue #273。生年月日を厳密な暦日 `PayrollDate` として受け、40歳到達日の属する保険月から65歳到達日の属する保険月の直前までを年齢対象として判定する。誕生日の前日が到達日なので、1日生まれは前月、1月1日生まれは前年12月となる。2月29日生まれも対象月は2月。現在時刻・端末timezone・給与支払日の年齢を利用しない。

一次情報（2026-10-10 JST確認）:
- https://www.kyoukaikenpo.or.jp/shibu/ibaraki/public_relations/009/index.html （40歳／65歳の前日、5月1日／2日の保険月例）
- https://www.nenkin.go.jp/shinsei/kounen/tekiyo/sonota/20120314-04.html （海外居住・施設等の適用除外と年齢到達時の届出不要）

この型は年齢の境界だけを返す。加入資格・適用除外・保険者固有条件・個別適用on/off・標準報酬月額・率・端数処理を推測しない。生年月日未登録は対象外0ではなく判定未完了として呼出側が扱う。保険月を給与控除月／支払月へ変換する会社設定は別の処理とする。既存 `PersonnelFamilyMember.ageOn` の一般年齢表示を置き換えない。
