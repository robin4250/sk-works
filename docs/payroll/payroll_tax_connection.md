# 会社料率・月額所得税から給与明細への接続

## 対象と操作

個別給与設定の「給与の税計算・自動反映」から、適用開始月ごとに計算条件を保存する。未登録は従来の所得税・社会保険固定月額を保持する。登録しただけで全従業員を自動方式に切り替えない。住民税は既存の通知月額・適用月方式を引き継ぐ。

会社料率方式は健康保険・介護保険・厚生年金・雇用保険・子ども子育て支援金を対象とする。加入・免除は管理者が確認し、健康保険と厚生年金の標準報酬月額を別々に入力する。健康保険等を単純に実支給額へ乗じない。介護の40歳到達月〜65歳到達前月は保険適用月と生年月日で判定する。1日生まれは前月境界。自由控除に同名の法定控除が残っている場合は重複計算せず条件確認にする。

月払いの所得税は国税庁令和8年月額表の甲・乙を支払日で選択する。日給・時給の人でも月払い給与なら月額表を使う。日払い、賞与、年末調整、他年度の税額表はこの計算方式の対象外。扶養人数は申告書上の人数（加算分を含む）、乙は従たる給与の申告書で認められる人数のみ。アップロードした未検証PDFを計算ルールとして採用しない。

非課税支給額・雇用保険対象外額は登録した月額を使う。支給額からの単純な推測はしない。追加社会保険料等は「他項目で既に控除した分」の所得税計算上の控除であり、新たに手取りから引く金額ではない。個々の課税区分が不明な給与調整は、適用前に担当者が確認する。

## 計算経路

- 会社料率の既存historyから給与対象月に有効な最新適用月・版を選択。将来の率で過去の下書きを上書きしない。保険適用月・給与対象月・支払月のオフセットも検証する。
- 出勤・手当・月給・有給の既存集計結果と給与調整の追加支給を保険料・所得税の対象へ渡す。給与調整自体を二重に支給へ追加しない。
- 従業員負担率の固定精度整数（百分率の百万分の一）を使用。雇用保険率を折半しない。
- 健康保険・介護・支援金を合算して50銭以下切捨て／超過切上げ。内訳は健康→介護→支援金の累計差分で端数を配賦。厚生年金・雇用保険はそれぞれ給与控除の端数処理。特約による別端数処理は固定月額方式を利用する。
- 公式月額表231行×8甲欄・乙欄、105,000円未満と740,000円以上の算式、7人超・乙の扶養控除を実装。公式PDFのSHA256を記録。
- 控除合計・差引支給額・明細内訳へ同一結果を保存。再読込だけで版や承認を変えない。税率と個別条件の根拠は確定帳票snapshotに保存する。
- 料率未設定・支払年の税額表未対応では出勤保存を巻き戻さず、給与を計算停止とする。未計算PDFは出力せず、確定も拒否する。条件保存時に既存対象下書きが未計算になる場合は保存全体を拒否する。
