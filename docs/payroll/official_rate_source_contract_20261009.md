# 給与料率の公式資料・検証契約

確認日：2026-10-09 JST。Issue #273の税率設定の実装準備。
公式情報の確認結果であり、ユーザー指定の初期設定値ではない。
資料取得・候補表示・利用者の適用・実際の給与計算は別の状態として扱う。

会社都道府県だけで協会けんぽ加入を断定しない。健康保険組合等の場合は対応する保険者の正式資料が必要。
公式入口が変更・未取得・判別不能なら確認失敗として表示し、既存の設定値を維持する。
取得できた資料でも対象条件が会社と一致するまでは適用候補として採用しない。

## 所得税の取り違え防止

国税庁2026年表は2026年給与等が対象で、2025年以前への使用を禁止している。
月額表、日額表、賞与表と電子計算機による計算方法は別資料。
給与形態が日給であることだけで日額表を選ばず、該当資料の適用要件を確認する。
所得税は所得税と復興特別所得税を併せた源泉徴収表を使うため、後から復興分を二重加算しない。
家族手当の対象人数、社会保険の扶養人数、税額表の扶養親族等の数は同じ値と推測しない。
PDF資料を登録した状態と、数値表／計算ルールを検証して計算可能になった状態を分ける。

## 月の取り違え防止

協会けんぽの2026健康保険資料と支援金資料では開始する保険料対象月が異なる。
会社設定に保険料対象月、給与控除対象月、納付月を区別して保存する。
資料の「納付分」をそのまま給与適用開始年月へコピーしない。
雇用保険の年度と所得税の暦年も区別し、すべてを1月自動切替へ統一しない。

## 生年月日と介護資格月

公式説明：https://www.kyoukaikenpo.or.jp/shibu/ibaraki/public_relations/009/index.html
資格取得は40歳誕生日の前日の属する月。1日生まれでは誕生日の前月となる。
既存PersonnelFamilyMember.ageOnは通常年齢表示用なので、給与の対象月判定へそのまま転用しない。
生年月日、資格対象月、給与控除月を分けて判定する。
65歳到達時、うるう日生まれ、会社の当月／翌月控除と保険者例外も公式資料を照合してテストする。
未登録・不正な生年月日は自動対象外へ落とさず未確認にする。

## 候補と適用の契約

候補資料はURL、発行元、年度／期間、取得日時、資料hash、対象区分、検証状態を持つ。
同一URLの資料差替えもhashと検証versionを分けて履歴を残す。
画面には現在値、確認候補値、保険料対象月、出典を並べ、差異だけを「変更あり」とする。
明示確認ポップアップ後に選ばれた項目だけ更新し、取得処理から給与設定の保存処理を呼ばない。
旧version照合と変更履歴の書込を一transactionにし、競合や履歴保存失敗時は適用を成立させない。
所得税共通資料の検証者による公開承認と、会社管理者による適用承認も区別する。
