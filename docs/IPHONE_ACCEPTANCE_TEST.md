# SKO iPhone受入テスト

実機インストール後は、この順番で確認する。

## A. 初回登録とセキュリティ

- [ ] 携帯電話番号をIDとして入力できる
- [ ] 本パスワードを2回入力し、不一致時に登録されない
- [ ] SMS承認コードが届く
- [ ] 正しいSMSコードで認証できる
- [ ] 「本パスワードを忘れた方」から登録済み携帯番号へSMSを送れる
- [ ] 未登録の携帯番号でパスワード復旧用アカウントが新規作成されない
- [ ] 新しい本パスワードを2回入力し、SMS確認成功後に即時更新される
- [ ] SMS確認後のパスワード更新に失敗した場合はログイン状態を残さない
- [ ] 初回ログイン時は第2パスワード設定を強制されない
- [ ] 第2認証対象画面を初めて開いた時に第2パスワードを2回設定できる
- [ ] 第2パスワード不一致時に設定されない
- [ ] 第2認証対象画面でFace IDを有効化できる
- [ ] 本人氏名・会社名・住所・連絡先を登録できる
- [ ] 振込先金融機関・支店・種別・口座番号・名義を登録できる
- [ ] 管理者の会社・本人基本情報は初回登録で必須となり、「後で登録」で通常ホームへ進めない

## A2. 従業員招待・本登録

- [ ] 会社メンバーなら役割に関係なく「従業員登録」を開ける
- [ ] 名前と携帯電話番号だけで招待を作成できる
- [ ] 管理者の従業員登録画面には「サブ管理者にする」「承認担当者にする」が表示される
- [ ] 一般ユーザー・サブ管理者の従業員登録画面には役割・承認担当者指定を表示しない
- [ ] 「承認担当者にする」をONにすると「サブ管理者にする」も自動でONになる
- [ ] 承認担当者が3名いる状態で4人目を指定すると、現在の3名と「この人を外す」「閉じる」が表示される
- [ ] 入れ替え対象を選ぶと、新しい従業員の本登録と同時に承認担当者が入れ替わる
- [ ] 初期パスワードを共有シートからSMS/メッセージへ渡せる
- [ ] 招待QRコードを表示できる
- [ ] 相手側で招待QRコードを読み取ると電話番号・初期パスワードを利用できる
- [ ] 初期パスワードでログイン後、本パスワードを2回設定できる
- [ ] 住所・血液型・家族構成・緊急連絡先を登録できる
- [ ] 本人写真・マイナンバーカード表面/裏面を登録できる
- [ ] 本人情報送信後、管理者と承認担当者に本登録通知が届く
- [ ] 管理者または承認担当者の1人が本登録すると利用開始できる
- [ ] 本登録完了後、承認通知が消える
- [ ] 会社指定の未提出書類がある間はホーム最上部に大事な通知が出続ける
- [ ] 必要書類をすべて登録すると大事な通知が自動で消える

## C. 出勤・退勤

### 手動
- [ ] 一般ユーザーが自分の出勤登録できる
- [ ] 一般ユーザーが自分の退勤登録できる
- [ ] サブ管理者も自分の出勤・退勤を登録できる
- [ ] 管理者も自分の出勤・退勤を登録できる
- [ ] 管理者/サブ管理者の本人打刻と管理用の出勤・人区管理が別機能として使える

### GPS自動出勤
- [ ] 出勤方法の「位置情報」が「GPS自動出勤」表記になっている
- [ ] GPS自動出勤を選ぶと曜日とGPS取得時間を設定できる
- [ ] 設定した曜日・時刻が本日の勤務報告に表示される
- [ ] GPS自動出勤を使う時だけiPhoneの位置情報「常に許可」を案内する
- [ ] 指定時刻の前後5分で、選択中現場の基準位置付近なら自動出勤になる
- [ ] 現場付近にいない場合は出勤登録せず「GPS自動出勤は出勤を登録しませんでした」と通知される
- [ ] 同じ日の自動出勤が二重登録されない
- [ ] GPS自動出勤をOFF/別方式へ変更するとバックグラウンド位置取得を止める

### 位置情報＋写真
- [ ] カメラが起動する
- [ ] 撮影キャンセル時は登録されない
- [ ] 写真付きで出勤/退勤確認を保存できる
- [ ] 保存写真が当日の日報に紐付き「出勤確認写真」として見られる
- [ ] 写真一覧で日付・社員・出勤/退勤ごとに確認できる
- [ ] 写真をピンチで拡大できる
