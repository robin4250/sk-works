# SKO iPhone受入テスト

実機インストール後は、この順番で確認する。

## A. 初回登録とセキュリティ

- [ ] 携帯電話番号をIDとして入力できる
- [ ] 本パスワードを2回入力し、不一致時に登録されない
- [ ] SMS承認コードが届く
- [ ] 正しいSMSコードで認証できる
- [ ] 「本パスワードを忘れた方」から登録済み携帯番号へSMSを送れる
- [ ] 未登録の携帯番号でパスワード復旧用アカウントが新規作成されない
- [ ] 新しい本パスワードを2回入力し、SMS確認成功後に即時更新される
- [ ] SMS確認後のパスワード更新に失敗した場合はログイン状態を残さない
- [ ] 初回ログイン時は第2パスワード設定を強制されない
- [ ] 第2認証対象画面を初めて開いた時に第2パスワードを2回設定できる
- [ ] 第2パスワード不一致時に設定されない
- [ ] 第2認証対象画面でFace IDを有効化できる
- [ ] 本人氏名・会社名・住所・連絡先を登録できる
- [ ] 振込先金融機関・支店・種別・口座番号・名義を登録できる
- [ ] 管理者の会社・本人基本情報は初回登録で必須となり、「後で登録」で通常ホームへ進めない

## A2. 従業員招待・本登録

- [ ] 会社メンバーなら役割に関係なく「従業員登録」を開ける
- [ ] 名前と携帯電話番号だけで招待を作成できる
- [ ] 初期パスワードを共有シートからSMS/メッセージへ渡せる
- [ ] 招待QRコードを表示できる
- [ ] 相手側で招待QRコードを読み取ると電話番号・初期パスワードを利用できる
- [ ] 初期パスワードでログイン後、本パスワードを2回設定できる
- [ ] 住所・血液型・家族構成・緊急連絡先を登録できる
- [ ] 本人写真・マイナンバーカード表面/裏面を登録できる
- [ ] 本人情報送信後、管理者と承認担当者に本登録通知が届く
- [ ] 管理者または承認担当者の1人が本登録すると利用開始できる
- [ ] 本登録完了後、承認通知が消える
- [ ] 会社指定の未提出書類がある間はホーム最上部に大事な通知が出続ける
- [ ] 必要書類をすべて登録すると大事な通知が自動で消える

## B. 一般ユーザーホーム

- [ ] 会社名、本人名、一般ユーザー表示が分かりやすい
- [ ] 本日の出勤・本日の退勤がすぐ押せる
- [ ] 給与明細、プロフィール、現場登録、設定、ヘルプが表示される
- [ ] 出勤表・現場・チャット・メニューの下部5タブが常時使える
- [ ] 同じ機能の不要な重複ボタンがない
- [ ] 右上ベルから通知センターを開ける

## C. 出勤・退勤

### 手動
- [ ] 一般ユーザーが自分の出勤登録できる
- [ ] 一般ユーザーが自分の退勤登録できる
- [ ] サブ管理者も自分の出勤・退勤を登録できる
- [ ] 管理者も自分の出勤・退勤を登録できる
- [ ] 管理者/サブ管理者の本人打刻と管理用の出勤・人区管理が別機能として使える

### 位置情報
- [ ] 出勤/退勤ボタンを押した時だけ位置情報許可が求められる
- [ ] 常時GPS追跡を要求しない
- [ ] 現場基準位置との距離判定が表示される

### 位置情報＋写真
- [ ] カメラが起動する
- [ ] 撮影キャンセル時は登録されない
- [ ] 写真付きで出勤/退勤確認を保存できる

## D. 出勤表

- [ ] 月曜日始まりで表示される
- [ ] 5週または6週の週タブになる
- [ ] 前月/翌月の日付が薄く表示される
- [ ] 現場名が中心に表示される
- [ ] 出勤・退勤時刻が表示される
- [ ] 残業、早出、夜間、手当タグが表示される
- [ ] 勤務なしは「休み」になる
- [ ] 月間カレンダーへ移動できる
- [ ] A4プレビューを開ける
- [ ] 出勤表の印刷ボタンでiOS印刷ダイアログが開く

## E. 日報

- [ ] 朝の出勤情報から現場・メンバーが自動表示される
- [ ] 作業内容を入力できる
- [ ] メンバーごとに残業・早出・夜間・手当を設定できる
- [ ] 指で責任者サインを書ける
- [ ] サイン後は「サイン済み・確定」になる
- [ ] 確定した内容が出勤表へ反映される
- [ ] 確定後は直接変更できない
- [ ] 修正申請を送れる
- [ ] 管理者が設定した承認担当者（1〜3名）のうち1名が承認すると編集可能になる
- [ ] 承認担当者に設定された1〜3名だけに「承認待ち」が表示される
- [ ] 管理者本人でも承認担当者から外れていれば「承認待ち」は表示されない
- [ ] 個人事業主・一人親方は管理者本人1名を承認担当者として運用できる
- [ ] 再サインで再確定できる
- [ ] A4プレビューでサインを確認できる
- [ ] 日報の印刷ボタンでiOS印刷ダイアログが開く
- [ ] 印刷PDFにも手書き責任者サインが表示される

## F. チャット

- [ ] 「すべて」タブ
- [ ] 「現場」タブ
- [ ] 「個別」タブ
- [ ] 管理権限時のみ「協力会社」タブ
- [ ] 個別で名前検索できる
- [ ] 最近会話した個別トークが上へ来る
- [ ] 現場トークが利用状況に応じて優先表示される
- [ ] テキスト送受信できる
- [ ] 写真を送信できる
- [ ] ファイルを送信できる
- [ ] 写真が会話内に表示される
- [ ] ノートへ移動できる
- [ ] アルバムへ移動できる

## G0. 管理者初回設定

- [ ] 管理者初回登録で会社名と本人情報を登録できる
- [ ] 初回管理者本人がworkersへ自動的に紐付く
- [ ] 会社・本人基本登録を完了するまで通常ホームへ入らない
- [ ] 会社独自の必要書類を決められる
- [ ] 書類本体の提出は後からでもよい
- [ ] 初回現場で現場名・請求先会社名・現場住所・最寄り駅・現場単価を登録できる
- [ ] 消費税率・福利厚生費率を登録できる
- [ ] 残業・早出・夜勤・休日出勤単価を登録できる
- [ ] 任意名称の手当を最大3つ登録できる
- [ ] 4段階完了後に通常SKOホームへ進める
- [ ] 通常利用開始後も「設定 > 会社単価・手当設定」から税率・福利厚生費率・残業・早出・夜勤・休日出勤・手当3つを変更できる
- [ ] サブ管理者・一般ユーザーには会社単価・手当設定を表示しない
- [ ] 既存会社は初期設定ウィザードへ戻されない

## G. 管理者ホーム・権限

- [ ] 管理者用ホームになる
- [ ] 出勤・人区管理
- [ ] 人員管理
- [ ] 請求書
- [ ] 管理者用現場データ
- [ ] 承認担当者に設定されている管理者だけ「承認待ち」が表示される
- [ ] サブ管理者の権限チェックを変更できる
- [ ] 権限OFFの機能はホームから消える
- [ ] 権限OFFの機能を別導線から開こうとしても拒否される

## H. 第2認証

- [ ] 一般ユーザーが給与明細を開く時に第2認証を要求する
- [ ] サブ管理者も自分の給与明細を開く時に第2認証を要求する
- [ ] サブ管理者には請求書・管理者用現場データ・現場単価・給与管理を表示しない
- [ ] 管理者が請求書を開く時に第2認証を要求する
- [ ] 管理者が管理者用現場データを開く時に第2認証を要求する
- [ ] 必要書類・資格証は第2認証なしで開ける
- [ ] 第2認証後にアプリをバックグラウンドへ送り、戻ると再認証を要求する
- [ ] 間違った第2パスワードを拒否する
- [ ] 5回失敗で一時ロックする
- [ ] Face ID設定時にFace IDで開ける

## I. 請求書

- [ ] 月表示
- [ ] 年表示
- [ ] 左右で前後期間へ移動
- [ ] 会社別表示
- [ ] 請求書A4プレビュー
- [ ] 税率設定
- [ ] 法定福利費率設定
- [ ] 振込先設定
- [ ] テンプレート表題・備考設定
- [ ] 印刷ボタン
- [ ] 保存ボタン
- [ ] メールボタン

印刷はiOS印刷ダイアログ、保存・メールはPDF共有シートへ接続済み。実機ではAirPrint、ファイル保存、メールアプリ共有を最終確認する。

## J. プロフィール・給与明細

- [ ] 氏名変更
- [ ] 電話番号変更
- [ ] 電話番号変更時、新しい番号へのSMS確認が必須になる
- [ ] SMS確認後、新しい番号でログインIDが更新される
- [ ] プロフィール写真選択
- [ ] 給与明細は最新月から過去順
- [ ] 月を選択してA4プレビューを表示
- [ ] 給与明細の印刷ボタンでiOS印刷ダイアログが開く
- [ ] 他人の給与明細を一般ユーザーが読めない
- [ ] 一般ユーザーは他人の必要書類・資格証を読めない
- [ ] 人員管理権限のないユーザーは他人の電話番号・メール・備考を取得できない
- [ ] 請求書閲覧権限のないユーザーは顧客の請求先住所・支払条件などを取得できない

## K. レイアウト

- [ ] iPhone縦画面で横切れしない
- [ ] キーボード表示時に保存ボタンが押せる
- [ ] 長い会社名・現場名で崩れない
- [ ] 文字サイズを大きくしても主要ボタンが操作可能
- [ ] 戻る操作で意図しないデータ消失がない


## L. 説明書・パンフレット

- [ ] 一般ユーザーは一般ユーザー用10ページ説明書を開ける
- [ ] サブ管理者はサブ管理者用15ページ説明書を開ける
- [ ] 管理者は管理者用20ページ説明書を開ける
- [ ] 3役割すべてからSKOパンフレット20ページを開ける
- [ ] プロフィールとヘルプの両方から「使い方・説明書」へ進める
- [ ] 各説明ページに「⭕ ここを押す」、操作手順、サポート・補足が表示される
- [ ] A4 PDFプレビューを開ける
- [ ] iOS印刷ダイアログを開ける
- [ ] PDF共有シートを開ける
- [ ] 管理者用説明書に「サブ管理者は請求書・現場単価対象外」という誤った管理者向け文言が混ざっていない
