# SKO iPhone受入テスト

実機インストール後は、この順番で確認する。

## A. 初回登録とセキュリティ

- [ ] 携帯電話番号をIDとして入力できる
- [ ] 本パスワードを2回入力し、不一致時に登録されない
- [ ] SMS承認コードが届く
- [ ] 正しいSMSコードで認証できる
- [ ] 重要情報用の第2パスワードを2回設定できる
- [ ] 第2パスワード不一致時に登録されない
- [ ] Face IDを有効化できる
- [ ] 本人氏名・会社名・住所・連絡先を登録できる
- [ ] 振込先金融機関・支店・種別・口座番号・名義を登録できる
- [ ] 会社情報を「後で登録」にした場合も再開できる

## B. 一般ユーザーホーム

- [ ] 会社名、本人名、一般ユーザー表示が分かりやすい
- [ ] 本日の出勤・本日の退勤がすぐ押せる
- [ ] 給与明細、プロフィール、現場登録、設定、ヘルプが表示される
- [ ] 出勤表・現場・チャット・メニューの下部5タブが常時使える
- [ ] 同じ機能の不要な重複ボタンがない
- [ ] 右上ベルから通知センターを開ける

## C. 出勤・退勤

### 手動
- [ ] 出勤登録できる
- [ ] 退勤登録できる

### 位置情報
- [ ] 出勤/退勤ボタンを押した時だけ位置情報許可が求められる
- [ ] 常時GPS追跡を要求しない
- [ ] 現場基準位置との距離判定が表示される

### 位置情報＋写真
- [ ] カメラが起動する
- [ ] 撮影キャンセル時は登録されない
- [ ] 写真付きで出勤/退勤確認を保存できる

## D. 出勤表

- [ ] 月曜日始まりで表示される
- [ ] 5週または6週の週タブになる
- [ ] 前月/翌月の日付が薄く表示される
- [ ] 現場名が中心に表示される
- [ ] 出勤・退勤時刻が表示される
- [ ] 残業、早出、夜間、手当タグが表示される
- [ ] 勤務なしは「休み」になる
- [ ] 月間カレンダーへ移動できる
- [ ] A4プレビューを開ける
- [ ] 出勤表の印刷ボタンでiOS印刷ダイアログが開く

## E. 日報

- [ ] 朝の出勤情報から現場・メンバーが自動表示される
- [ ] 作業内容を入力できる
- [ ] メンバーごとに残業・早出・夜間・手当を設定できる
- [ ] 指で責任者サインを書ける
- [ ] サイン後は「サイン済み・確定」になる
- [ ] 確定した内容が出勤表へ反映される
- [ ] 確定後は直接変更できない
- [ ] 修正申請を送れる
- [ ] サブ管理者2名承認後に編集可能になる
- [ ] 再サインで再確定できる
- [ ] A4プレビューでサインを確認できる
- [ ] 日報の印刷ボタンでiOS印刷ダイアログが開く
- [ ] 印刷PDFにも手書き責任者サインが表示される

## F. チャット

- [ ] 「すべて」タブ
- [ ] 「現場」タブ
- [ ] 「個別」タブ
- [ ] 管理権限時のみ「協力会社」タブ
- [ ] 個別で名前検索できる
- [ ] 最近会話した個別トークが上へ来る
- [ ] 現場トークが利用状況に応じて優先表示される
- [ ] テキスト送受信できる
- [ ] 写真を送信できる
- [ ] ファイルを送信できる
- [ ] 写真が会話内に表示される
- [ ] ノートへ移動できる
- [ ] アルバムへ移動できる

## G. 管理者ホーム・権限

- [ ] 管理者用ホームになる
- [ ] 出勤・人区管理
- [ ] 人員管理
- [ ] 請求書
- [ ] 管理者用現場データ
- [ ] 承認待ち
- [ ] サブ管理者の権限チェックを変更できる
- [ ] 権限OFFの機能はホームから消える
- [ ] 権限OFFの機能を別導線から開こうとしても拒否される

## H. 第2認証

- [ ] 請求書を開く時に第2認証を要求する
- [ ] 管理者用現場データを開く時に第2認証を要求する
- [ ] 間違った第2パスワードを拒否する
- [ ] 5回失敗で一時ロックする
- [ ] Face ID設定時にFace IDで開ける

## I. 請求書

- [ ] 月表示
- [ ] 年表示
- [ ] 左右で前後期間へ移動
- [ ] 会社別表示
- [ ] 請求書A4プレビュー
- [ ] 税率設定
- [ ] 法定福利費率設定
- [ ] 振込先設定
- [ ] テンプレート表題・備考設定
- [ ] 印刷ボタン
- [ ] 保存ボタン
- [ ] メールボタン

印刷はiOS印刷ダイアログ、保存・メールはPDF共有シートへ接続済み。実機ではAirPrint、ファイル保存、メールアプリ共有を最終確認する。

## J. プロフィール・給与明細

- [ ] 氏名変更
- [ ] 電話番号変更
- [ ] 電話番号変更時、新しい番号へのSMS確認が必須になる
- [ ] SMS確認後、新しい番号でログインIDが更新される
- [ ] プロフィール写真選択
- [ ] 給与明細は最新月から過去順
- [ ] 月を選択してA4プレビューを表示
- [ ] 給与明細の印刷ボタンでiOS印刷ダイアログが開く
- [ ] 他人の給与明細を一般ユーザーが読めない

## K. レイアウト

- [ ] iPhone縦画面で横切れしない
- [ ] キーボード表示時に保存ボタンが押せる
- [ ] 長い会社名・現場名で崩れない
- [ ] 文字サイズを大きくしても主要ボタンが操作可能
- [ ] 戻る操作で意図しないデータ消失がない
