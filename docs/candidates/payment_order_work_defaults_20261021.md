# 注文書の工事名・工事場所の設定連動

基準: main d70b90b9f19f854e8f13c00c4a1e66fbfeb4235e（build 6）。本人iPhoneの更新成功はユーザー申告済み。

支払証明書設定内の「注文書の設定」に工事名・工事場所を追加し、保存した既定値を新規注文書の自動生成と編集画面の両方へ渡す。空欄は元帳票の既定値を維持する。既存の特記事項も同じ設定から渡す。保存済み別添・確定済み帳票は自動上書きせず個別確認・保存を維持する。

サーバーは private.trade_document_template の許可文字列に payment_certificate 限定で2項目を追加する。各240文字。未知の関数本文では停止する。既存OID/owner/ACL/search_path/認可/CASを保持し、既存金融行・別添データを更新しない。旧サーバーは新項目を拒否するため、本番の関数照合・導入と新アプリの配布が両方必要。現時点で本番適用・配布なし。

検証: PGlite 0.3.14の既存月次別添fixtureと税額fallback統合fixtureが成功。保存→workspace読取、240文字制限、型/別種/別会社/閲覧者拒否、CAS、関数metadata保持、既存別添不変、未知本文拒否を確認。Dart formatterによる構文読取成功。Flutter 3.47.5取得後の起動がcloud metadata宛通信を発生させ自動承認レビューで拒否されたため、Flutter analyze/testは未実施。迂回や再実行なし。pubspec.lock変更なし。
