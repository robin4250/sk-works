# 請求書の承認時期：未接続UI候補

対象月が終わってから、対象勤務の退勤・日報確定をサーバーが確認できたときに担当者へ承認ボタンを表示する画面部品。既存画面・既存の承認RPCには未接続で、本候補だけでは現在の承認を制御しない。main・本番・配布への適用はしない。

サーバー返却の `invoice_id` と `source_revision` の一致を必要とし、状態 `period_open`、`checkout_pending`、`report_pending`、`ready` を表示する。未知・失敗・未照合・古いrevisionは承認できない。管理者の権限と担当者本人の権限は別判定。ルート、未リンク勤怠、月内の過去の未完了などは端末で推測せず、DB側が全範囲を判断する。`data_changed` は現在未確認として扱う。

サーバーが承認を同一transactionで再判定することが必須。確認後にデータが変わる競合や古いアプリは画面制御では防げない。既存データ・承認履歴・印影の変更は含まない。実サーバー契約、現行画面統合・認可・GoTrue・同時更新・実機確認は未完。
