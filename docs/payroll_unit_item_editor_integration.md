# 個別給与の単位別項目UI（未接続）

`PayrollUnitItemEditor`はWork担当の独立UI部品です。現在のアプリ画面には接続していません。支給／控除と時間／日にち／月の6グループに項目を追加・編集・削除し、項目名、単価、日報表示チェックを編集します。数量の記録・給与計算は含みません。

現在の`custom_earnings`／`custom_deductions`は`name`と`amount_yen`の直接金額です。単価をこの直接金額へ書き戻してはいけません。この部品はJSON変換・Repository呼出し・給与計算を持ちません。`onRegister`がない場合、登録ボタンは無効です。

## Mac担当との接続

- Mac担当が単位・数量・単価・日報表示・項目IDの保存／給与契約を確定する。
- 既存の直接金額、社会保険、住民税、給与形態ごとの単価を保持する読み込み／保存アダプターを用意する。直接金額項目を時間単価と推測変換しない。
- 社員ごとに安定したキーで部品を生成し、読み込み済みの`initialItems`を渡す。社員や保存済みデータを変更した場合は新しいキーで生成する。画面離脱と社員切替時の未保存確認は接続先画面の責務とする。
- `onRegister`は全6グループのスナップショットを受け取り、契約に沿って保存する。`new-unit-item-*`は編集中の識別子であり、DBのUUIDではない。アダプターが新規項目の正式IDを発行する。
- 保存失敗を例外として返すと入力が保持される。閲覧者は`canEdit: false`で表示する。
- 日報表示と日報数量からの給与反映を実際に検証してから既存画面へ接続する。

## 部品の操作説明

支給または控除を選び、時間・日にち・月を選択します。左下の「＋追加」で選択中のグループへ項目を追加します。名称・単価を編集し、必要なら「日報に表示」を選択します。「削除」は編集中の項目を除き、登録時には表示していないグループも含めて渡します。選択中のタブは青です。

接続時には既存画面の「？」ヘルプへこの操作を追記し、保存・日報表示・給与反映が利用可能な範囲と一致させます。未接続の機能を既存ヘルプに利用可能として記載しません。

320px・文字1.3倍、タブ間の入力保持、選択先への追加／削除、両区分の登録値、隠れた項目の検証、保存失敗時の入力保持、閲覧者／未接続時の登録不可をwidgetテストで検証します。実行結果はCIで確認し、未実行を成功扱いしません。
