# 資格写真申請の要対応接続候補
通常の資格写真申請は管理者または登録済み承認担当者の「承認待ち → 資格写真の承認待ち」で確認する。本人向け送信完了案内に行き先を示す。
既存RPC listが返す can_review=true / pending / photo_contract_version=1 だけを要対応と通知ベルへ投影する。通知テーブルへの新規書込みはなく、ベルから現在の承認待ちを確認する方式。承認後はpendingから除かれる。RPCの権限を広げず、自己承認条件も変更しない。
同じ資格のpendingをクライアントで再照合して重複送信を止める。既存の複数申請は削除・統合しない。このpreflightのみでは複数端末間競合を防げないため、サーバー側一意条件と古い既存pendingの取扱いは別途必要。
実認証・他社RLSの変更なし。本番の申請は読み取り集計のみ、個人ID・写真情報を取得・保存しない。ローカルFlutter未実行。CI/統合/本番/実機は別々に記録する。
