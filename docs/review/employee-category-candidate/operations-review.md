# Build 24 deployment review

本番への書込みはしていない。従業員区分は導入guardのNative CI成功済みだが、未使用復旧は新しい厳密catalog方式をCI検証中。会社・従業員参照FKは既存行の物理削除を拒否し、ensure初回参照が区分と監査を作成したら未使用復旧は不可。使用後は履歴を残し、機能の停止と前方修正を使用する。

資格マスターは別名・保有資格・申請が存在する削除を拒否する。会社削除が資格マスターを連鎖削除しようとする場合も同様に拒否する。会社を消して解決しない。画面には「関連する資格・別名・申請が残っているため削除できません。既存記録を保持してください」と案内する。今回の会社休止要件と整合するよう、会社機能の休止と物理削除は別に扱う。本レビューで会社休止APIは追加しない。

適用前: 最新mainと統合head、元関数/全policy/FK/trigger/ACLの直前照合、全業務行保持guard、復旧SQLと証跡の既存バックアップへの追記が必要。既存Libraryバックアップを上書き更新する担当はrootのみ。

復旧は導入直後に取得したcatalog hashを独立レビューして生成する。未使用の判定は全3表空。未知の依存はRESTRICTでトランザクション全体を失敗させる。実GoTrueと実機確認は別途必要。
