# LINE参加グループ一覧・通常SKOグループの連携先（ベータ版）

LINEトークの入口に「参加済みグループ一覧」ボタンを追加。同じ一覧を通常グループの新規作成と既存グループの参加メンバー画面にある「LINEトークを追加」で使用する。現場・オープン・個別トークには追加しない。

追加するものは実ユーザーの友達ではなく、LINEグループ名付きの連携先。参加メンバー内の名前から元の受信トークを開く。保存済み投稿を複製せず、現行の一意な外部イベントID、一次連携先、第2/3段階の請求書証拠を保持する。SKOからLINEへの送信は行わない。

署名検証後のgroup join/message/leaveでカタログを更新する。LINE公式のgroup summary GETから取得した名前のみ表示。名前取得失敗は過去の実名を保持し、名前がなければ「グループ名未取得」。退出情報と遅延再送の日時を比較し、同時刻の競合は不参加を優先する。

LINE Messaging APIには公式アカウントが参加中の全グループを列挙するAPIがない。既存binding/保存済みwebhookの既知グループIDは参加状況未確認として引き継ぎ、マスターによる再読み込みで公式summaryを照合する。200は現在の参加と実名、404は存在しない又は不参加、400/403/401/429/5xx/timeoutは過去の状態を維持する。受信記録のない以前からの参加グループは、次の署名済みイベントで追加される。トークの過去履歴を逆取得する機能ではない。

会社未割当グループはマスターのみ一覧可能。新しく会社に結び付ける操作は、マスターかつ当該会社のowner/adminが明示して選択した場合だけ。既存会社連携先は会社一致・元トークの既存閲覧権限・追加先通常グループの既存管理権限を要求する。アカウント失効/会社不一致/元トーク不可/現場/オープンはサーバーで拒否する。会社は自動推測しない。直接table権限は付与しない。

本番反映順はDB migration→webhook更新→認証済みmaster-only refresh Edge Function→Releaseアプリ。新機能のCI成功とmain反映は、実LINE投稿受信・実機表示・請求書実発行成功とは区別する。
