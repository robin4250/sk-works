# 自動下書き取引先の登録一覧除外

請求の未設定取引先は既存請求を保持する内部customerです。正規marker `customers.notes = 'sko_system_unassigned_invoice_customer'` だけを識別に使い、名称一致で削除・非表示にしません。

CLI 2.58.5の`migration new`で生成したforward migrationは、現本番2関数body hashを照合してからpg_get_functiondefの一意なWHERE境界だけを変更します。同期では新しい内部customerをtrade directoryへ写さず、workspaceは同会社のcustomer_idがmarkerに一致する既存trade行だけを返しません。代表者contact wrapperは元workspaceから読取するので、同じ除外が反映されます。

CREATE OR REPLACEによりowner・ACL・security definer・search_path・既存認可を保持。customer/trade/invoice行を更新・削除しません。既存取引会社の同期処理・契約単価・代表者情報・請求書を保持します。

PGlite 0.3.14で現本番関数原典とcontact wrapperを実行。migration前後のcustomer/trade/invoice digestと関数metadata一致、同名の通常customer表示、他会社markerは除外根拠にしない、customerなしを保持、future sync marker拒否、管理者条件維持、source変更時の停止を確認しました。

本番適用は未実施。適用前にrootが最新body hash/metadataと対象表backupを再確認し、トランザクション適用後に同じmetadata/data保持を照合します。rootが本番変更を調整し、他migrationをまとめて適用しません。
