# LINE履歴請求の4画面

基本は月別表・単価設定・請求書・元データ取込。既存チャット入口も保持する。
元データ取込で保存先を選択し、5MB以下のTXT/ZIPを選ぶと、過去の全対象月へ未確認候補を保存する。正式請求書の確定・発行は行わない。
読取時だけLINEの複数行引用符を解釈し、原文・投稿日時・fingerprintは保持する。10月投稿の9月勤務は勤務月で取り込む。
月別表の要確認・未振り分け欄で原文を見て行を追加し、日付・作業員・現場・数量・正式現場名を手入力する。キャンセルは追加行を残さない。
単価設定は現場別ページ。日単価初期32800円、残業はSKO標準式の日単価÷8×1.25で計算。PC/鉄骨各3000円、福利15%/税10%は入力初期値であり、既存会社設定を書き換えない。実数量と明示確認後に既存SKO請求の生成経路を使う。
保存済み履歴単価を初期値で置換しない。正式名称が月別表で一致する場合に単価設定へ引き継ぎ、保存小計から既存の正式下書きへ進む。

未完了：別投稿の配置報告と終了報告の突合せ、訂正投稿の手入力照合、実データ全月の数量確認、実機操作。コード公開/CI/本番保存/実請求発行は別に記録する。
