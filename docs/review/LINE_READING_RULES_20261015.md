# LINE 初期設定・読み取りルール

取込済み原文を頻度順で語句集計し、右側の振り分け先から現場・氏名・手当・勤務区分・残業・早出・対象外を選択する。
登録済み現場・従業員の完全一致と既知の残業/早出だけを自動候補にする。複数候補は未設定、保存した手動ルールを優先する。
現場/従業員は登録済み対象の名称を選択可能。原文や出典は変更しない。

## 保存と権限

ルールはグループ単位、既存 LINE 利用/グループ参加/会社請求管理権限を毎回確認。
私有テーブルは RLS と権限剥奪。公開 RPC は invoker、私有 definer 内で既存 line_import_access を呼び出す。
revision 競合防止・初回挿入の排他・入力型/長さ/重複検査。確定帳票や給与には変更しない。

## 検証

- pure Dart 4 cases: 頻度・原文不変・自動候補/曖昧・手修正/確定/出典保持
- isolated PGlite: 保存/再読込、revision競合、重複、別グループ、閲覧専用、匿名拒否
- Supabase changelog と functions docs を確認。新本番適用なし。
