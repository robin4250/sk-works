# Logout intent navigation quarantine

The existing repository gateway defers SDK sign-out until an already-dispatched mutation settles. The SDK may save and emit a late signedIn during that wait. A read-only, credential-free in-memory quarantine signal now changes synchronously on logout intent. The actual AuthenticatedNavigationBoundary consumes its snapshot and stream, disposes/hides the existing private Navigator on the next frame, and retains the safe screen through stalled mutation, late SDK login and stalled logout request. Remounting the boundary reads the pending snapshot before building its child.

Only successful completion of the real SDK local signOut, a fresh observed signedOut with null session, no intervening non-null event, and currentSession null release the fence. Cached signedOut is drained before invoking the SDK and cannot confirm completion. Failure leaves the fence closed, rejects new app-owned writes and displays an explicit local logout retry. No SDK credential/session is exposed by the signal, and raw AuthState events cannot clear a failed fence.

A retry with no remaining local session can confirm local sign-out without resending an old token. This does not prove that a previously failed server revocation succeeded. Retry does not re-enroll Apple, resend passwords or restore an old session. The existing first-sign-in onboarding exception and same-SID refresh behavior remain intact outside quarantine.

The signal is not durable across process death or cold restart. SDK storage persistence, all raw writers, OAuth/deep-link/recovery/automatic refresh ownership, server revocation and iPhone validation remain incomplete. Other SDK observers can still observe transient signedIn; this change protects the actual existing app navigation subtree after an app-owned logout intent. Apple adoption and individual document exemption remain OFF. No production/provider/DB/key/deployment changes.

Validation pending dedicated CI: actual pinned Supabase SDK with controlled HTTP and actual Navigator widgets exercises stalled mutation/request, late SDK signedIn, failed logout, safe retry, no stale token resend and boundary remount. Existing boundary/onboarding/refresh and gateway cases are included; no full TLS suite is manually repeated. Navigation-only changes are decoupled from the Apple preparation workflow; its existing Apple56 source/test commands remain intact. The workflow edit itself may run that suite once. Existing navigation-reset covers AuthGate and boundary changes; the new quarantine workflow also watches/analyzes the shared session-binding helper.
