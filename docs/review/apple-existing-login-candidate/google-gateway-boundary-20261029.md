# Existing Google gateway boundary

Regression-first evidence is separated by boundary. Initial test-only head619ee28c reproduced three stale membership acceptances (expected false, actual true), but its native fixtures lacked PKCE storage and therefore did not prove the native admission gap. Corrected test-only head26c7aa2, job123390310404, retained actual PKCE storage: both ordinary controls passed, three membership negatives still returned true, and both pending/failed logout native admission negatives returned without the required error. No provider/browser delivery occurred; the native launcher is a platform spy.

The gateway now owns a read-only, client-lifetime AuthState revision observer, not SDK mutation ownership. It drains only the cached exact-session baseline and clears that temporary session reference. Every subsequent live SDK event invalidates outstanding external admissions; logout intent invalidates synchronously. A first live boundary during admission cannot be mistaken for cached replay. Stream error or completion permanently closes the external view and cancels its observer; a newly created client is required. Ordinary successful refresh allows a new admission after its event drains. This conservative error behavior matches the global navigation stream-error restart guidance; no new recovery UI is introduced.

ExistingGoogleLogin membership reads capture this admission and fixed user/bearer, then check the same revision and current bearer through the final synchronous return. There is no per-read subscription cancellation await in which SDK A→B→A history could be lost. Observed A→B→A, same-SID fresh signedIn, stream error and app-owned logout intent reject stale results. An ordinary unchanged SDK membership read remains accepted.

For iOS native launch, the exact existing SDK getOAuthSignInUrl provider/redirect/prompt/PKCE parameters are retained. The wrapper checks admission after its asynchronous result and again after actual PKCE URL preparation, immediately before the native handoff. Its launcher options remain platformDefault and webOnlyWindowName _self. No URL is logged or persisted by this wrapper. A logout during PKCE storage awaits prevents native handoff; a logout after handoff can reject the launch result but cannot recall the already-open browser.
