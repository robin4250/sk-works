# SKO 社内試験・かんたん操作ガイド

画面が表示される最新版で試してください。この案内は実装に合わせた操作説明です。iPhoneでの動作確認がすべて終わったことを示すものではありません。操作に迷ったら各画面右上の「？」を開いてください。

## 会社を検索して連携する（会社管理者）

1. 「設定」→「会社検索・連携設定」で「会社検索・連携申請を利用する」をONにします。相手の会社にもONにしてもらいます。初期状態はOFFです。
2. 取引会社・協力会社の一覧にある「会社を検索・連携申請」から、会社名・法人番号を2文字以上入力して「検索」を押します。
3. 会社名・住所・法人番号を確認し、「連携申請」を押します。開始月を選び、表示される会社間の関係を確認して「申請」を押します。
4. 相手の管理者は「受信・送信履歴」で会社情報・開始月を確認し、「承認」→「確認」を押します。承認後に双方の一覧へ反映されます。

取引会社側からの申請では自社が相手の協力会社になり、協力会社側からの申請では自社が相手の取引会社になります。承認前は「申請取消」が使えます。受信側は「却下」も選べます。社員情報・給与・契約単価は自動共有されません。

## 連携会社の変更情報を確認する（会社管理者）

1. 「設定」→「連携会社情報の更新確認」で「会社情報の変更通知・更新確認」をONにします。新しい変更通知には変更元・受信側の両方のONが必要です。
2. 更新候補が届いたら、右上のベル、または同じ設定ページから開きます。
3. 会社名・住所・電話番号・メールアドレス・法人番号の「旧」と「更新候補」、更新日時を比較します。
4. 採用する場合は「更新する」→「確認」。維持する場合は「今回は更新しない」→「確認」を押します。

候補を見るだけでは登録内容は変わりません。OFFにすると更新承認が止まり、履歴は残ります。対象が見つからない場合は所属会社・権限を確認してください。

## LINEの語句を振り分ける（LINEマスター権限）

1. 「元データ取込」で新規のTXT・ZIPファイルを選びます。
2. 「単価設定」→「初期設定・読み取りルール」で対象の履歴を選びます。
3. 回数順の語句から、直したい語句の区分ボタンを押します。「自動候補・確認してください」は予測です。振り分け先と「正式名称・読み取り値」を確認し、必要なら登録済みの対象を選び直して「設定」を押します。
4. 最後に「読み取りルールを保存」を押します。設定は次回の新規読み取りに使われます。

元の投稿や保存済みの行は、この保存だけでは書き換わりません。語句が出ない場合は元データの取り込みと選択した履歴を確認してください。

### 「（仮）」の数量だけ直す

「月別の表」で対象月を開き、「（仮）」の数値を押します。正しい時間を入力して「この数値を採用」を押すと、その欄だけを修正・採用できます。時間のない残業・早出は仮1時間です。他の数量・仮状態は残ります。

行を開いて内容を確認し、「確認済みにする」を使う場合も、残る仮値の採用チェックが必要です。仮状態が残る行は確認済み集計・正式請求へ進めません。参考額をそのまま正式額として扱わず、全行の確認・LINEノート照合・保存の後、現場別単価と正式下書きプレビューを確認してください。

### 保存済みの行にルールを使い直す

1. 月別表で編集中の変更を保存してから「保存済み未確認行へ語句ルールを再適用」を押します。
2. 「語句ルールの再適用」で現場・従業員の変更前後を比較し、必要なものだけ「この項目を採用」を押します。「採用予定」はまだ保存されていません。
3. 保留の候補は登録済み対象を選び直します。同名で決められない場合は月別表で個別編集します。
4. 「採用した項目だけ保存」を押します。

対象は自動生成の由来が確認できる未確認行です。確認済み・手修正・除外した行や、由来を確認できない古い行は保護されるので月別表で個別編集してください。数量・原文・ほかの仮状態は変わらず、自動で確認済みにはなりません。

## 友達を探して、既存のトークを開く

1. チャット画面の「友達一覧」を押します。
2. 「友達検索」に氏名・SKO IDを入力して、登録済みの友達を絞り込みます。見つからなければ検索文字を消して一覧へ戻します。
3. 友達を押して公開名・SKO IDを確認し、「チャットを始める」で既存の個別チャットを開きます。

左から右へのスワイプでピン留め・解除ができます。この端末のログイン中ユーザーごとに保存されます。新しい友達への申請は、下の「追加」→「ID検索」から行い、相手が「届いた申請」で承認します。

写真・所属会社は現在未確認です。「電話番号通知」は準備中で送信されません。この画面の検索対象は友達の氏名・SKO IDで、トーク本文や全履歴の検索ではありません。

## ボタンが押せない・保存できないとき

表示された案内を読み、必要な権限・所属会社・機能のON/OFF・接続を確認してください。保存の競合が表示された場合は再読込して最新の内容を見直します。画面にない機能や準備中の機能は、今回の試験操作に含めません。
