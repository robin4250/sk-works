# 会社角印の選択・表示設定

## 確定仕様

会社管理者が会社データ内で設定する。帳票ごとや従業員ごとの重複設定を作らない。

- 会社角印のON／OFFを請求書・給与明細・支払証明書へ共通反映する。
- OFFは角印のみ非表示。確認印・承認印・履歴・金額・会社情報・帳票配置を保つ。
- 初期値ONで既存会社の表示を維持する。
- 管理者が設定でき、サブ管理者・閲覧者・他社からの変更を拒否する。
- 同じ生成済みPDFをプレビュー・印刷・保存・共有に使う。設定変更後は帳票を開き直して再生成する。

## 5種類比較PDF（未完成）
