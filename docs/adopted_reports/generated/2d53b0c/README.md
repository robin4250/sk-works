# Bold company-seal report samples

Generated by Flutter from commit 2d53b0c884e6e7f7caab821ccf26fe5140386578 in Actions run 37706602085. These samples replace brush lettering with the bundled Noto Sans JP Bold company-name seal. A4 report geometry and nonzero amounts were visually inspected. Original adopted masters remain unchanged.

Later fixes cover zero quantities, short-company tagline collision and registered-company previews without attendance; these archived nonzero samples are a historical comparison point, not proof of those later behaviors. Final generation tests output those scenarios in the Actions `adopted-report-pdf-comparison` artifact.

Regeneration: use pinned Flutter 3.47.5, run `python tool/prepare_pdf_fixture_font.py /tmp/sko-pdf-font.ttf`, set `SKO_PDF_FONT_PATH=/tmp/sko-pdf-font.ttf` and `SKO_PDF_OUTPUT_DIR=/tmp/sko-report-pdfs`, then `flutter test test/adopted_invoice_pdf_generation_test.dart test/adopted_payroll_pdf_generation_test.dart test/payment_certificate_pdf_generation_test.dart`. Install the PyMuPDF/fontTools versions pinned in the Flutter workflow before generation.

Pixel identity with the unembedded original CJK fonts is not asserted. Device display, share and physical printing require Release verification on iPhone.
