# SKO Personal Work Wallet

Product idea: SKO remains useful when a person changes jobs because their personal work data follows their own SKO account while company-owned records remain with the company.

## Before public launch: foundation only

- Separate personal data ownership from company membership.
- Employment termination disconnects membership; it does not delete the personal SKO account.
- Personal data: profile, personal SKO ID, qualifications/certificates, personal documents.
- Company data: payroll, invoices, company approvals/admin records.
- Shared history: attendance/site history may remain as history but is not automatically transferable to a new employer.
- Keep personal SKO ID hidden from current UI until the transfer/personal-wallet service is ready.

## Future personal mode

- User-facing entry: 「わたしの仕事データ」.
- No-company state remains usable as a personal wallet.
- New employer can invite an existing SKO user; the person authenticates and explicitly approves which transferable personal data is shared.
- Do not make name/birthdate an open directory. Recovery/discovery must protect user privacy.
- Future worker verification QR can be added without changing the ownership model.

## Ads

- Company/workspace experience remains ad-free.
- Future free personal-wallet mode may be ad-supported.
- Sensitive wallet/work data must not be supplied as ad-targeting input.
- Paid personal tier may later offer ad-free/storage or advanced features.

This foundation must not delay the current TestFlight candidate.
