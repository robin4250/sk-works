# Company seal lettering

The company seal uses the original, unmodified **青柳隷書しも 2.01** TrueType font.
It is generated from the registered company name; no company-specific seal image or name is embedded.

On 2026-10-08 the user explicitly accepted a seal with a similar appearance to `IMG_0367.png` (「似たような感じで良いですよ」). This approval applies to seal lettering only. Adopted invoice and payroll layouts remain unchanged.

## Source and integrity

- Official distributor: https://opentype.jp/aoyagireisho.htm
- Original archive: https://opentype.jp/bin/aoyagireisyosimo_ttf_2_01.zip
- Font filename: `aoyagireisyosimo_ttf_2_01.ttf`
- Font SHA256: `a4c55ad5f72e65a482931d967725e97ff206eb3019c87281d9e5514a63bb8db9`
- Copyright holder stated by distributor: SIMO; calligraphy by 青柳衡山.
- The original font maps 14,963 Unicode characters, including JIS second-level kanji and hiragana.
- OS/2 embedding permission `fsType`: 8 (editable embedding).

## Original distribution requirements

`original-use-instructions.txt` is the unchanged original `フォントの使用方法.txt` (CP932 encoding).
`original-font-description.pdf` and `.doc` are unchanged copies of the supplied `フォントの解説` files.
These names are made portable for the application asset bundle; file bytes have not been modified.
All original instructions and descriptions accompany the redistributed font and are bundled as Flutter assets.

The original instructions allow commercial use without use conditions and free redistribution, require including the instructions and font description, and prohibit charging for redistribution of the font itself. The font is a free bundled resource, not a paid font product. Notification is not required for normal use or redistribution. The original instructions, rather than this summary, govern usage.
