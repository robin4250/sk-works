## Ambiguous unquoted TOC root records

PostgreSQL17's [PrintTOCSummary](https://github.com/postgres/postgres/blob/REL_17_STABLE/src/bin/pg_dump/pg_backup_archiver.c) prints description, namespace, tag and owner as unquoted space-separated fields. [sanitize_line](https://github.com/postgres/postgres/blob/REL_17_STABLE/src/bin/pg_dump/dumputils.c) replaces CR/LF with spaces and explicitly notes that name fields are not automatically parseable. Inspected source blobs: `67ecdde27526c5f1b51f9f16116f6fb2f032afe5` and `3347b9e4a463ba9028961f2a232e2e131fa4be17` respectively.

The earlier split-based table lookup incorrectly accepted `TABLE public worker_personnel_profiles backup postgres` as the current table even when the actual tag was `worker_personnel_profiles backup`. It also collapsed trailing tag whitespace into the owner separator. Root table and recognized function records now require exact raw single-space separators and a simple ASCII owner name (`[A-Za-z_][A-Za-z0-9_$]*`); additional tokens, doubled separators and unsupported owners stop rather than selecting a candidate. Legitimate whitespace/non-ASCII/punctuation owners are conservatively unsupported. Function signatures and the public/private separation remain unchanged.

These checks only reject an ambiguous textual subset. They do not make unquoted TOC text an authoritative identity source: names containing CR/LF may already have been normalized, and field boundaries cannot generally be recovered. `current_roots_complete` means only all four textual candidates were found; `root_identities_verified` remains false. A separately reviewed structured archive/source metadata and OID/name/signature comparison is required before any extraction/restoration plan. No archive, production connection, collector, SQL or Mac operation was used for this correction.

Validation: four new regression methods first produced nine assertion failures plus the missing-report-field error on the old mapper. The corrected mapper passes all 16 methods, including the existing 12 tests, normal four roots, duplicate IDs, private-only identity and public-alias refusal. Tests use synthetic TOC strings only.
